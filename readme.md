# To-Do Website

A simple and interactive To-Do List web application built using **HTML, CSS, and JavaScript**. This project allows users to add, complete, and delete tasks efficiently.

## Features

* Add new tasks dynamically
* Mark tasks as completed
* Delete tasks from the list
* Responsive and user-friendly interface
* Efficient event handling using **Event Delegation**

## Concepts Used

### DOM Manipulation

The application dynamically updates the webpage by creating, modifying, and removing HTML elements through JavaScript DOM methods.

### Event Delegation

Instead of attaching event listeners to every task item individually, a single event listener is attached to the parent container. This improves performance and ensures that dynamically added tasks are handled correctly.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Learning Outcomes

* Understanding the Document Object Model (DOM)
* Implementing Event Delegation for better performance
* Managing dynamic user interactions
* Building interactive web applications with vanilla JavaScript
